# Docker Installation Guide

A beginner-friendly GitHub project that explains how to install Docker on Ubuntu, Windows, and macOS.

## What is Docker?

Docker is a platform used to build, run, and manage applications inside containers.

## Supported Platforms

- Ubuntu
- Windows
- macOS

## Quick Start: Ubuntu

Run the following command:

```bash
chmod +x scripts/install-docker-ubuntu.sh
./scripts/install-docker-ubuntu.sh
